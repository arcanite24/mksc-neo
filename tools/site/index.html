A native C/SDL3 re-implementation of Mario Kart: Super Circuit (US) for macOS, Linux, Windows, Android and the web. Optional enhancements: any resolution and aspect ratio, unlocked framerate, local split-screen, modern menus, and a modding API for tracks, karts, items, rules and Lua scripts.

You need your own US ROM (.gba, or a .zip containing it). No game content is distributed here: on first start the game imports your ROM locally.

Play in the browser

Open the web build

  • Runs as WebAssembly in current Chrome, Edge, Firefox and Safari.
  • The ROM is imported inside the page and kept in this browser's storage (IndexedDB), with saves, settings, records, ghosts and mods. Nothing is uploaded.
  • Works offline after the first load. Clearing the site's data removes everything.
  • Controllers use the Gamepad API: press a button once so the browser exposes the pad. Keyboard: arrows steer, Z accelerate, Down brake, Shift hop, C item, Enter/Esc confirm/back in menus.

PlatformInstall
macOSUniversal (Apple Silicon and Intel), macOS 11+. Unzip and move MKSC Neo.app to Applications. The app is not notarized: the first time, Control-click it and choose Open.
Linuxx86-64, glibc 2.31+, X11 or Wayland. Extract and run ./mksc.
Windowsx64. Extract and run mksc.exe (keep SDL3.dll next to it). For the unknown-publisher warning: More info, then Run anyway.
Androidarm64, Android 8+. Install the APK (allow installs from your browser or file manager).
WebThe same build as Play, zipped to host yourself. Serve the folder over HTTP(S); opening the HTML file directly does not work.

Each release lists SHA256SUMS.txt for verifying downloads. Older versions: all releases.

Credits

MKSC Neo started from the aplerdal/mksc decompilation of Mario Kart: Super Circuit. The original game's behavior (physics, collision, AI, items and data formats) was recovered from that work and re-implemented as native C. Third-party code and fonts are listed in LICENSE-NOTICE.md.
